# 결론

이 가이드를 통해 여러분은 Kiro의 다양한 기능을 직접 다뤄보았습니다. 포함된 주요 기능은 다음과 같습니다.

- **Steering 파일**: 복잡한 프로젝트를 AI 에이전트가 효과적으로 탐색하고 작업할 수 있도록 안내

- **기본적인 Vibe 코딩**: 버그 수정, 단순한 변경 및 리팩토링을 위한 직관적 코딩

- **명세 기반 개발(Specification Driven Development)**: 대규모 변경을 위한 요구사항, 설계, 작업 계획 수립

- **Hooks**: 프로젝트에서 반복적으로 발생하는 boilerplate 작업을 자동화

- **MCP (Model Context Protocol)**: Kiro의 능력과 행동을 확장하고 맞춤화
