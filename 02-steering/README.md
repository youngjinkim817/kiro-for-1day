# 스티어링

## 스티어링이란?
스티어링은 프로젝트에 관한 지속적인 지식을 제공하는 방법입니다. `.kiro/steering/` 디렉토리의 마크다운 파일을 통해 매번 채팅에서 규칙을 설명하는 대신, 스티어링 파일을 참고하여 Kiro가 설정된 패턴, 라이브러리, 표준을 일관적으로 따르도록 보강합니다.

**주요 장점**

- 일관된 코드 생성: 모든 컴포넌트, API 엔드포인트, 테스트가 팀의 설정된 패턴과 규칙을 따릅니다.

- 반복 설명 감소: 매 대화마다 프로젝트 표준을 설명할 필요가 없습니다. Kiro가 여러분의 선호사항을 기억합니다.

- 팀 합의: 프로젝트 신규 개발자든 숙련된 기여자든 모든 개발자가 동일한 표준으로 작업합니다.

- 프로젝트 지식이 확장됨: 코드베이스와 함께 성장하고 프로젝트 진행에 따른 결정사항과 패턴을 기록하는 문서입니다.
